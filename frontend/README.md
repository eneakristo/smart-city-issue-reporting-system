# Frontend

React frontend prepared for a modular medium-size application structure.

Suggested source organization:

- `src/app`: shared application layout
- `src/assets`: static assets
- `src/components`: reusable UI and navigation components
- `src/context`: app-wide providers and lightweight state
- `src/hooks`: custom hooks
- `src/pages`: route-level pages
- `src/router`: route definitions
- `src/services/api`: API access layer
- `src/types`: shared TypeScript types

Included routes:

- Home
- Login
- Register
- Report Issue
- Issues List
- Issue Details
- My Reports
- Admin Dashboard
- Duplicate Reports

Business logic is intentionally not implemented yet.
